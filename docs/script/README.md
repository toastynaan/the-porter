# The script

Every conversation in the game, how they link, and what each answer does. Generated by `tools/script_docs.py` from the game's own files, so it is always what the game plays: run it again after editing a script. The script itself is in each chapter's folder (`game/chapters/<chapter>/dialogue/*.talk`, the lane's in `game/chapters/common/lane/`). Faces and reading people: `docs/systems/faces.md`. Writing a conversation: `docs/systems/dialogue.md`.

## How to read it

**A night's map** (sequence diagram): the night's beats run down the page in order (`Note over Alric, The night`). Under each, a solid arrow from *The night* is a talk the beat opens itself (the traveller on the ride); a solid arrow from *Alric* is someone he can go and talk to from then on. A dashed arrow is a flag one talk sets and another reads. The last note lists what passes on to later chapters.

**A conversation** (flowchart): every point is a box with its first line; every answer is a solid arrow labelled with what Alric says, its stance in brackets if it answers a claim, and its condition; a dotted arrow is a jump with no answer. A claim is a six-sided box; a stance arrow is green if it's the right read, red if wrong. `again` (the next time) is blue-grey; `leave` (if he walks away) is dashed. Under it, *Every line* opens the whole script with faces and effects.

## Reading people

| The claim is | Believe | Press | Confront (with proof) |
| --- | --- | --- | --- |
| true | **right**, trust +2 | wrong, trust −2, they close up | wrong, trust −10, they remember |
| hiding | wrong: he never hears the rest | **right**, trust +1, they tell the rest | too hard, trust −5, they close up |
| a lie | wrong: he never hears the truth | half: they dig in and close up | **right**: the truth; the cult: Suspicion +10 |
| mistaken | wrong: he takes their error for his own | **right**, trust +1: they think again | **right**, trust +2: they're shown |
| misleading | wrong: he goes where they point | **right**: he isn't led | **right**; the cult: Suspicion +10 |

Moods: *calm*, *warm*, *glad*, *amused*, *grave*, *sad*, *weary*, *afraid*, *wary*, *angry*, *cold*, *ashamed*, *pleading*, *pained*, *drunk*, *blank*. Tells: *glance*, *look down*, *look away*, *swallow*, *blink*, *lip*, *jaw*, *brow*, *smile*, *still*, *nod*, *shake*, *flinch*.
